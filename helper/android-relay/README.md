# Phone ADB Relay

Android 8+ 手机组件，包名 `fun.acat.phonerelay`。提供 TCP 中转和本机 ADB 控制两种服务，各自启动与停止；同签名覆盖安装保留参数和 ADB 身份。

## 本机 ADB 控制

App 的「连接」「无线配对」「更新」「中转」页签分别管理对应设置，顶部持续显示连接状态。连接页填写插件配对码和本机 ADB 地址、端口；更新页检查和确认系统安装。

1. 在插件「ADB 连接」选择「使用 App 控制」，设置 App 接入端口，保存并重载。默认 `6190`；局域网或外部系统 VPN 连接需发布此 TCP 端口。内置组网通过虚拟网入口连接插件回环，WireGuard 服务端模式需发布其 UDP 监听端口。
2. 在 插件页面左侧的「Relay App」填写手机可访问的插件主机名或 IPv4，获取配对码。配对码包含连接凭据，只填入自己的手机 App。
3. 手机开启本机 TCP ADB，填写本机地址及连接端口；Android 11+ 也可开启无线调试，使用配对端口和六位配对码完成配对，再填写无线调试的连接端口。配对端口与连接端口分别设置。
4. 填入插件配对码并启动 App 控制。App 通过固定证书 TLS 主动连接插件，通信可经直连网络或现有 VPN。

内置组网时，WireGuard与ZeroTier把App接入端口从虚拟网转发到插件回环，入口仅接收配置手机IPv4；ZeroTier须先授权节点并填写手机组网IP。Tailscale用户态节点通过其入站回环机制连接插件，访问权限由tailnet ACL控制。外部系统VPN使用主机组网地址，容器按其网络部署发布App端口。

同机无线配对时，将系统无线调试页面和 Relay App 以分屏同时显示，保持配对窗口打开并及时填写端口和验证码。完成后使用无线调试首页显示的连接端口。

组网登录、本机ADB配对、插件App配对分别完成；本机无线连接端口与配对临时端口不同。TCP中转模式由插件侧ADB授权，App控制模式由Phone Relay本机身份授权。表单按保存的连接方式显示适用参数，切换后保存重载刷新，隐藏参数保留。

App 内置 ADB 客户端连接本机 adbd，命令以设备实际提供的 shell 权限执行。支持设备状态、shell、应用操作、点击/长按/滑动、按键、中文输入、剪贴板、截图和 UI 节点。中文输入先经手机端 scrcpy 控制通道确认剪贴板，再执行一次系统粘贴并检查命令退出状态；插件通过当前节点核对实际输入值，核对失败时重新聚焦当前编辑框并按原语义重试一次。启动控制组件和连接控制通道都有超时，本机 ADB 不响应时返回明确错误。节点使用单次文件采集后回传，完成时清理临时文件。

播放音频、连续音频片段与双向文件传输通过会话认证的数据子连接提供。切换前停止手机任务，在插件配置中选择连接方式并重载；隐藏的直连参数保留。App 断线、取消或请求超时后不重放操作。本机无线连接端口变化时可启用自动发现恢复；系统无线调试与VPN需分别就绪。

App 画面来源可选「scrcpy 视频取帧」或「按需截图」。视频由手机端 scrcpy 采集并通过 MediaCodec 解码；保持就绪时通过独立连接推送 JPEG，关闭保持就绪后按需取帧并在空闲90秒释放视频组件。插件端 scrcpy 按直连模式的配置启动，App 模式保留这些配置。

同一插件配对凭据绑定一台 App 设备身份；更换手机或卸载重装后，在「Relay App」页面重置配对并重新填写配对码。重置需设备任务空闲。

## HTTP(S) 抓包

控制请求的响应通过布尔字段 `rpc_ok` 标记调用是否完成；抓包状态中的 `error`、`failures` 保留代理流量的诊断信息。状态查询成功时返回诊断详情；调用执行失败时向插件报告操作错误。

在插件启用流量抓包后选择「App 抓包」，手机启动回环 HTTP(S) 代理并通过已认证连接上传最近请求、响应文本和媒体地址。支持 HTTP/1.1、分块传输、gzip 文本，二进制与其他正文编码记录元信息。每条响应正文最多8000字符，队列64条，过载丢弃数在状态中显示。抓包CA身份在手机私有目录原子保存，公开CA可从插件页面下载。

选择 mitmproxy 时，手机回环代理通过同一插件接入端口的独立固定证书 TLS 子连接传输，绑定当前设备、控制会话和抓包身份；插件代理只监听回环地址。App 控制的两种抓包方式都由插件管理启动、停止和设备租约。

系统 CA 信任方式需要本机 adbd 已有 root 或已授权 su；手动 CA 由目标 App 信任下载的证书。系统证书目录根据 Android 实际 Conscrypt 路径配置，自有挂载按目录身份核对后撤回。已有应用需重新打开以读取系统信任库；证书固定的应用可能拒绝解密连接。设备看门狗在连接失效后撤回本实例代理，保留之后设置的代理。

## TCP 中转

1. 手机开启网络 ADB（可由已授权 USB ADB 执行 `adb tcpip 5555`）。
2. 官方 WireGuard、Tailscale 或 ZeroTier 客户端连接同一网络，并在应用分流中允许本 App。
3. 填写手机组网 IPv4 与唯一允许的插件组网 IPv4，启动中转。组件在 tun/wg 接口地址的 `15555` 端口监听，目标为本机 `127.0.0.1:5555`。
4. 插件选择「直连」，配置相应组网 ADB 目标端口为 `15555`。

中转保留 ADB 自身授权，最多16对连接。接口消失后服务停止；通知和界面停止按钮回收连接。启动采用 `START_NOT_STICKY`，由用户重新启动。

## App 更新

插件随包提供 `bin/android/phone-adb-relay.apk` 及版本清单。App 的「更新」页点击「检查 App 更新」，确认有新版本后下载；包名、签名、递增版本码、大小和 SHA256 校验通过，再点击「确认系统安装」。Android 可能要求先允许本 App 安装应用；用户取消安装时保留当前版本。

APK 版本独立于插件 metadata 版本。首次安装及未提供更新按钮的版本，可在 Dashboard 下载 APK 后覆盖安装。更新会中断 App 进程；安装后重新打开 App 并启动控制，已有配置和 ADB 密钥保留。无需 GitHub Release 或单独更新服务。

## 构建

需要 JDK 17+、Python 3、Android SDK platform35 与 build-tools35.0.0。依赖固定版本、下载地址及 SHA256 见 `dependencies.json`。构建者可替换依赖并重新构建；第三方许可见项目根 `THIRD_PARTY_NOTICES.md` 和 `licenses/`。

```bash
export JAVA_HOME=<JDK目录>
export ANDROID_HOME=<SDK目录>
export OUT_DIR=<构建缓存中的绝对输出目录>
export SIGNING_KEYSTORE=<私有签名密钥路径>
# SIGNING_PASSWORD 由构建环境注入
bash build.sh
bash test.sh
```

输出 `phone-adb-relay.apk` 与 `phone-adb-relay.json`，均放入插件 `bin/android/`。签名密钥由维护者保管；构建目录使用工作区缓存。APK 经 zipalign 与 v2/v3 签名校验，内置 scrcpy5.0.1 控制组件及第三方许可。

宿主测试使用实际 LibADB 依赖，核对远端关闭后的缓冲尾部及无符号字节读取，并覆盖重复中文输入的粘贴次数、确认顺序和失败传播。

手机视频可在控制连接期间保持就绪，帧在手机内解码并按需压缩；关闭保持就绪后90秒空闲释放。截图使用实际采集时间校验新鲜度，手机操作完成后后续截图等待操作后的帧。

手机录制将H264与AAC直接封装MP4，音频单独录制输出M4A；时长与体积有界，控制连接结束时清理自有录制。成品通过绑定控制会话的一次性只读数据通道传输。连接页提供App抓包公开CA导出及系统证书设置入口，证书私钥保存在App私有目录。

保持手机视频就绪时，手机通过独立认证连接推送JPEG，插件只在内存保留最新一帧；截图按250毫秒画面年龄和操作代次校验。画面年龄采用请求往返时钟的保守下界计算，网络排队不会把旧帧视为新帧；截图耗时与画面年龄在面板分别显示。关闭保持就绪后按需采集，90秒空闲释放手机视频资源。

本机 ADB 连接类源码位于 `src/io/github/muntashirakon/adb/AdbConnection.java`，基于 LibADB 3.1.1；建流使用确认状态和条件等待，取消或拒绝时清理待确认流。构建时从依赖 JAR 中排除同名连接类，使用该源码生成的类。宿主测试覆盖先到确认、虚假唤醒、拒绝和取消。

### 弱网推帧

App scrcpy 模式在原生配置中提供推帧长边、频率、JPEG 质量和可接受画面年龄，保存并重载插件生效。默认原始尺寸、10 帧/秒、质量 85、最大 250ms；弱网可先选长边 720、5 帧/秒、质量 65。传输帧在插件恢复手机屏幕尺寸，视觉点击与节点坐标统一。默认画面年龄包含网络与排队时间，超过上限拒绝；提高上限代表接受更旧画面。操作后的代次、会话和采集时间校验始终执行。自定义画质需手机支持传输参数协商；默认参数可直接兼容，能力不足时页面提示升级 App。

### 本机连接恢复与TCP中转

连接页可发现并验证本机无线调试连接端口；只接受属于本机接口的`_adb-tls-connect._tcp`服务，已有ADB身份授权通过后才保存。配对码窗口的临时端口用于交换密钥，连接端口来自无线调试首页。系统未发布发现服务时可手填；端口发现和开机恢复分别由默认关闭的开关控制。

运行中切换恢复开关会即时刷新服务的系统重启策略，连接保持运行；闲置服务保持停止。App系统安装完成后按此开关恢复已启动的控制连接，已停止的控制保持停止。开启恢复后，开机、App更新或系统回收可重建控制会话。本机无线调试、VPN与后台启动权限需就绪；系统拒绝时打开App启动控制。停止按钮会清除本次运行意愿。新会话只处理新请求，录制、文件传输和设备动作由插件重新请求。前台服务使用Android的[connectedDevice类型及权限](https://developer.android.com/develop/background-work/services/fgs/service-types#connected-device)。

自动恢复以系统分发开机或更新广播、允许后台启动前台服务为前提。系统或模拟器屏蔽开机广播时，打开App并点击「启动 App 控制」；后台启动被拒绝时显示系统错误及手动恢复指引。本机无线端口自动发现沿用已有ADB授权，系统无线调试需保持开启。

TCP中转提供组网监听端口（默认15555）与本机ADB目标端口（默认5555），目标也可填写无线调试连接端口；仅隧道接口指定源IP可访问，最多16个活动会话。转发原始ADB字节，TLS和ADB授权在插件ADB客户端与系统adbd之间完成。App主动回连的插件配对与此认证分别配置。

连接插件卡片可单独更改插件主机和端口，保存后停止再启动控制。Relay页面同时显示手机实际连接的插件地址和本机ADB端点，便于确认组网路径。

### 文件弱网传输

文件通道通过能力协商启用手机接收进度确认。插件每次发送一个有界数据块，等待手机已写入本机ADB的字节确认，再继续发送；完成后核对文件大小与SHA256并原子提交。读取以连续无数据15秒判断中断，有部分数据到达时继续；文件操作保留180秒总期限，超时和取消会清理临时文件。进度消息绑定控制会话和一次性数据身份，断线释放等待。

连接后本机ADB地址和端口显示实际使用值，修改前停止控制。自动发现成功时同步表单端点，自动恢复被系统阻止的原因在连接页保留。

视频帧通道协商逐帧接收确认。插件收完整帧后释放下一帧的采集额度，手机据此取最新画面；配置频率作为上限，实际频率受传输和编码耗时限制。每条认证数据连接独立核对递增帧序号，重复与错误确认会结束该通道。

二进制下载协商消费确认：手机最多保持64KiB未确认数据，插件每次读取到部分数据即释放额度。停止、断线与取消会释放发送等待；15秒没有消费进度时结束该通道。录制文件与普通文件共用该限制，音频通道的实际速率仍受网络带宽约束。

低带宽中继可采用长边360、1帧/秒、JPEG55，按真实画面年龄判断是否满足使用要求。原始PCM播放音频为48kHz、双声道、16位，约192KB/s；持续实时采样需要对应带宽，低带宽可选择手机录制AAC音频片段后回传。

文件上传以手机实际写入本机ADB的字节进度计算15秒空闲期限；重复确认不延长等待。单次上传保留180秒总期限，完成后核对SHA256并原子提交。

组网接入
WireGuard / Tailscale / ZeroTier · 手机与插件加入同一网络

          
先在插件配置的「组网」开启开关，选择服务并填写参数。手机安装对应官方客户端，连接同一网络；Android 同时启用一种 VPN。
ADB 转发使用手机组网 IP；无 root Android 可运行 Phone ADB Relay 中转。抓包通过服务端组网 IP 与抓包端口连接，请在网络控制台限制授权成员与端口。
打开 Tailscale 登录授权
Tailscale/ZeroTier 的抓包卡片选择 mesh 后，通过服务端组网地址传输；WireGuard 使用 adb 反向转发。无 root 可选择 manual 信任方式并下载 CA，由手机或 App 自行信任；HTTPS 需 App 接受该 CA。
